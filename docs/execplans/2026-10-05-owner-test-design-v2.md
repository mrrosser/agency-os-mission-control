# Separately authorized revised owner email

This change adds one server-defined revised owner test, `gallery-owner-design-v2-2026-10-05`, while retaining the original `gallery-owner-single-test-2026-10-04`. It does not introduce a reusable mailing endpoint, contact import, campaign launch or real newsletter enrollment.

## Identity and compatibility

- Original run IDs, artifact hash inputs, MIME behavior and stored records are unchanged. The original UI panel is receipt-only. Its API remains scoped to the original fixed identity.
- Revised run IDs use the same SHA-256 construction with the new fixed identity. Its artifact additionally binds design version and exact inline asset manifest. Requests cannot supply arbitrary versions, templates, assets, senders or recipients.
- Dedicated revised routes are `/api/crm/warm-reconnect/qa/revised/prepare` and `/send`. Send requires the literal reviewed identity, design version, exact artifact fingerprint and explicit one-test confirmation. Existing owner authorization and privately pinned recipient remain mandatory.
- Both versions retain a durable transaction claim before the single provider call. Sent, inflight and unknown outcomes prohibit retries. A race-loser response reads the same test version. No reset/delete endpoint exists.
- Preference capabilities resolve their own allowlisted run identity. Opening links only inspects and presets choices. Explicit POST confirmation and request replay protection remain restricted to the four QA collections.
